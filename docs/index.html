설치와 업데이트

Install and update

インストールとアップデート

Claude 앱에서 해요. 폰도 돼요.

Done in the Claude app. Works on a phone too.

Claudeアプリで行います。スマホでもできます。

준비 (처음 한 번만)

Before you start (once)

準備（最初に一度だけ）

  1. 폰 브라우저(앱 말고)로 claude.ai 설정 → 기능(Capabilities)을 열어요. 로그인이 안 되어 있으면 먼저 로그인하세요.
  2. 코드 실행 및 파일 생성을 켜요.
  3. 네트워크 허용(Allow network egress)을 켜요. 이 항목은 앱 설정에는 없어서 브라우저에서만 켤 수 있어요. 한 번 켜면 앱에도 그대로 적용돼요. 계정에 따라 기본으로 꺼져 있어요.
  4. 앱으로 돌아와 새 대화를 열어서 진행하세요. 이미 열려 있던 대화에는 바뀐 설정이 적용되지 않아요.
  5. 새 대화에서도 막히면 설정이 반영되기까지 몇 분 걸릴 수 있어요. 5분쯤 뒤에 다시 시도하세요.
  1. In your phone's browser (not the app), open claude.ai Settings → Capabilities. Sign in first if you aren't.
  2. Turn on Code execution and file creation.
  3. Turn on Allow network egress. This option isn't in the app's settings, so you can only turn it on in a browser. Once it's on, it applies to the app too. Some accounts have it off by default.
  4. Go back to the app and start a new chat. Chats that were already open don't pick up the new setting.
  5. If a new chat is still blocked, the setting can take a few minutes to apply. Try again in about 5 minutes.
  1. スマホのブラウザ（アプリではなく）で claude.ai 設定 → 機能（Capabilities） を開きます。ログインしていない場合は先にログインしてください。
  2. コード実行とファイル作成をオンにします。
  3. ネットワークアクセスを許可（Allow network egress）をオンにします。この項目はアプリの設定にはないので、ブラウザでしかオンにできません。一度オンにすればアプリにも反映されます。アカウントによっては初期状態でオフです。
  4. アプリに戻って新しいチャットを開きます。前から開いていたチャットには新しい設定が反映されません。
  5. 新しいチャットでもブロックされる場合、設定の反映に数分かかることがあります。5分ほど待ってからもう一度試してください。

Getting started

はじめに

이름과 세계만 고르면 돼요. 나머지는 주사위가 정해 줘요.

Just pick a name and a world. The dice decide the rest.

名前と世界を選ぶだけです。残りはダイスが決めます。

  • 죽으면 인생 결산이 나오고, 그 뒤에 다른 세계의 다른 몸으로 회귀해요. 지난 삶의 능력도 하나 물려받아요.
  • 이 게임은 claude.ai 아티팩트에서만 돌아가요. 내 아티팩트로 띄우는 방법은 README에 있어요.
  • 입력할 때 말과 행동은 그대로 쓰세요. 속마음이나 상황 설명만 *별표* 안에 적으면 돼요. 별표 안의 내용은 장면 속 누구도 듣지 못해요.
  • 화면은 브라우저 언어에 따라 한국어, 영어, 일본어 중 하나로 시작해요. ⚙ 설정 → 화면 언어나 새 게임 화면의 🌐에서 언제든 바꿀 수 있고, 이야기 언어는 저장마다 시작할 때의 언어로 이어져서, 화면 언어를 바꿔도 진행 중인 이야기는 그대로예요. 입력은 아무 언어로 해도 돼요. 서술은 이야기 언어로 나와요.
  • When you die, the Life Review sums up your life, then you regress into a different body in a different world, carrying one ability from the life before.
  • The game runs only as a claude.ai artifact. How to publish your own copy is in the README.
  • Write speech and actions as they are. Put only thoughts or scene notes inside *asterisks*; no one in the scene hears what's inside them.
  • The game starts in English, Korean or Japanese depending on your browser. Switch any time in ⚙ Settings → Language or with 🌐 on the new-game screen. Each save keeps the story language it began in, so switching the screen language never changes a story in progress. You can type in any language; the narrator answers in the story language.
  • 死ぬと人生の決算で一生が締めくくられ、前世の能力をひとつ持って別の世界の別の体に回帰します。
  • ゲームはclaude.ai のアーティファクトでのみ動きます。自分用に公開する方法は README にあります。
  • 台詞と行動はそのまま書き、心の声や状況の説明だけを *アスタリスク* で囲みます。囲んだ中身は場面の誰にも聞こえません。
  • ゲームはブラウザの言語に合わせて英語、韓国語、日本語のどれかで始まります。⚙ 設定 → 言語（Language）や新しいゲーム画面の 🌐 でいつでも切り替えられます。物語の言語はセーブごとに始めたときの言語で続くので、画面の言語を変えても進行中の物語は変わりません。入力はどの言語でもよく、語りは物語の言語で返ってきます。

켜면 스릴이 있어요

  • 켜면 더 어렵고 스릴 있어요.
  • 선택지 주사위는 위험한 행동이나 확률이 붙은 선택지가 성공할지 실패할지 정해요.
  • 생활 주사위는 내 행동과 상관없이 가끔 행운이나 불운을 가져와요. 억울한 불운이 올 때도 있어요.
  • AI가 아니라 코드가 굴려서 결과가 한쪽으로 쏠리지 않아요.
  • d100을 굴리고, 숫자가 낮을수록 좋아요. 성공 확률이 60%면 60 이하가 나와야 성공이에요.

On: more thrills

  • Harder and more thrilling.
  • Choice dice decide whether risky actions, and choices that show a chance, succeed or fail.
  • Daily dice bring the occasional good or bad luck, whatever you do. Sometimes the bad luck feels unfair.
  • The code rolls them, not the AI, so results don't lean either way.
  • It's a d100 and lower is better: at a 60% chance, you need 60 or under.

オン：スリルがある

  • 難しく、スリルがあります。
  • 選択肢のダイスが、危険な行動や確率付きの選択肢の成否を決めます。
  • 日々のダイスが、何をしていても時々幸運や不運を運んできます。不運が理不尽に感じることもあります。
  • 振るのはAIではなくコードなので、結果がどちらかに偏りません。
  • d100で低いほど良いです。成功率60%なら60以下で成功です。

끄면 자유로워요

  • 주사위 없이 개연성에 따라 이야기가 흘러가요.
  • 내가 원하는 전개를 대체로 따라가고, 일부러 불리하게 꼬지 않아요.
  • 선택지에 확률이 붙지 않아요. 선택지는 참고용 제안일 뿐이에요.
  • 내가 쓴 대로 이야기가 흘러가는 롤플레이를 원하면 이쪽이 잘 맞아요.
  • 다만 없는 아이템이나 힘이 있다고 선언하면 허풍으로 처리돼요. 켜든 끄든 똑같아요.

Off: more freedom

  • No dice; the story goes by what's plausible.
  • It mostly follows where you want the story to go and doesn't twist things against you on purpose.
  • Choices show no odds; they're only suggestions.
  • The better fit if you want roleplay where the story follows what you write.
  • Still, declaring an item or power you don't have is treated as a bluff, dice on or off.

オフ：自由に遊べる

  • ダイスなしで、ありそうかどうかで物語が進みます。
  • おおむね望む方向に物語が進み、わざと不利にひねったりしません。
  • 選択肢に確率は付かず、あくまで提案です。
  • 書いたとおりに物語が進むロールプレイをしたい人に向いています。
  • ただし、持っていないアイテムや力を宣言するのは、ダイスのオン・オフに関係なくハッタリとして扱われます。

/판정으로 방금 판정의 이유 묻기

Ask why a check went that way with /why

/why で判定の理由を聞く

  • /판정은 주사위를 새로 굴리는 명령이 아니에요. 방금 판정이 왜 그렇게 나왔는지 물어보는 명령이고, 게임 속 시간은 흐르지 않아요.
  • 이유가 규칙이나 기록과 맞지 않으면 AI가 실수를 인정하고 바로잡을 수 있어요.
  • 판정이 이상하게 서술됐다면 먼저 이 명령으로 물어보세요. 주사위 결과 자체는 코드가 정한 값이에요.
  • /why does not reroll anything. It asks why the last check came out the way it did, and no time passes in the game.
  • If the reasoning doesn't match the rules or the record, the AI can admit the mistake and fix it.
  • If a check was narrated strangely, ask with this first. The dice result itself is set by the code.
  • /why は何も振り直しません。直前の判定がなぜそうなったかを聞くだけで、ゲーム内の時間も進みません。
  • 理由がルールや記録と合わなければ、AIが誤りを認めて直すこともあります。
  • 判定の語られ方がおかしいと思ったら、まずこれで聞いてください。ダイスの結果そのものはコードが決めています。

If the notes still don't fit, nothing is sent and the game tells you. A warning shows when ticked notes take over a third of the prompt. A save file carries its ticked notes, so importing it into another copy brings them along.

How the app picks pictures

アプリが画像を選ぶしくみ

인물

  • 세트 하나가 한 사람이에요. 표정(emotion)은 그 세트 안에서 장면에 맞는 얼굴을 골라요.
  • AI가 인물의 성별, 역할, 비중, 외형 단어, 소속을 설명해 줘요.
  • 코드가 그 설명을 세트의 태그, 역할, 분위기와 단어 단위로 비교해서 점수를 매겨요.
  • 정체 태그 faction:은빛기사단이 맞으면 점수를 크게 더해 줘요.
  • 세계(worlds)와 성별이 맞는 세트만 후보가 돼요. 많은 세트에 공통으로 들어 있는 단어(hair, smile)는 점수에 반영하지 않아요.
  • 비중(tier)이 비슷해도 점수를 더해요. 비중은 엑스트라, 조연, 주요로 나뉘어요.
  • 한 번 정해진 얼굴은 그 삶이 끝날 때까지 같은 사람에게 계속 쓰여요.

People

  • One set is one person. The emotion picks the face within that set that fits the scene.
  • The AI describes each person's gender, role, importance, look words and affiliation.
  • The code scores that against each set's tags, role and vibe, word by word.
  • An identity tag like faction:Silver Knights adds a big bonus when it matches.
  • Only sets whose worlds and gender fit are candidates. Words shared by many sets (hair, smile) don't count.
  • A similar importance (tier) also adds points. Tiers are extra, minor and major.
  • Once a face is chosen, it stays with that person for the rest of the life.

人物

  • 1セットが1人です。表情によって、そのセットの中から場面に合う顔を選びます。
  • AIが各人物の性別、役割、重要度、見た目の言葉、所属を説明します。
  • コードがそれを各セットのタグ、役割、雰囲気と単語ごとに照らし合わせて点数をつけます。
  • faction:新選組 のような所属タグが一致すると大きく加点されます。
  • 世界と性別が合うセットだけが候補です。多くのセットに共通する言葉（髪、笑顔）は数えません。
  • 重要度（ティア）が近いことも加点されます。ティアは extra、minor、major です。
  • 一度選ばれた顔は、その人生のあいだずっとその人物に使われます。

배경

  • AI가 장소를 영어 단어로 설명해요. 장소 종류를 먼저 적어요 (station, locker).
  • 코드가 이 세계의 배경 중에서 찾아봐요. 종류 단어가 전부 들어 있어야 후보가 돼요.
  • 시간대(day, night, sunset)에 맞는 버전을 골라요.
  • 애매하면 엉뚱한 그림을 붙이느니 그림을 아예 안 붙여요.
  • 가 본 곳에는 같은 그림을 다시 써요.

Backgrounds

  • The AI describes the place in English words, the kind of place first (station, locker).
  • The code searches this world's backgrounds. A background must contain every kind word to be a candidate.
  • It picks the version for the time of day (day, night, sunset).
  • When unsure, it shows no picture rather than a wrong one.
  • A place you've been reuses the same picture.

背景

  • AIが場所を英単語で説明します。場所の種類が先です（station, locker）。
  • コードがこの世界の背景を検索します。種類の言葉をすべて含む背景だけが候補です。
  • 時間帯（昼、夜、夕方）に合うバージョンを選びます。
  • 自信がないときは、間違った画像より画像なしを選びます。
  • 一度行った場所は同じ画像を使います。

  • Make them with AI: an anime-style generator such as NovelAI is a good choice. According to the site, generated images can be used commercially without restriction. Check the terms yourself before using them.
  • Free, openly licensed art: OpenGameArt lets you browse by license, such as CC0 or CC-BY. Always check each work's license.
  • itch.io assets are listed below. Check the license the artist states on each page.
  • Follow licenses as the artist states them. Check each page yourself before using anything.
  • AIで作る：NovelAI のようなアニメ調の生成サービスがおすすめです。サイトによれば、生成した画像は制限なく商用利用できます。使う前に規約を自分で確認してください。
  • 自由に使えるライセンスの素材：OpenGameArt では CC0 や CC-BY などライセンス別に探せます。作品ごとのライセンスを必ず確認してください。

  • ライセンスは作者が示すとおりに守ってください。使う前に各ページを自分で確認しましょう。

알려진 문제

Known issues

既知の問題

1. 같은 사람이 이름만 바뀌어 따로 생겨요

1. The same person shows up twice under different names

1. 同じ人物が別の名前で二人になる

AI가 가끔 대성통신 사장, 대성통신 주인처럼 같은 인물을 다른 이름표로 따로 만들어요. 이럴 땐 합치기로 하나로 합치면 돼요.

The AI sometimes splits one person into two labels, like Daesung Telecom boss and Daesung Telecom owner. When that happens, merge them into one.

AIはときどき、テソン通信の社長とテソン通信のオーナーのように、一人の人物を二つのラベルに分けてしまいます。そうなったら一つに統合してください。

미리 막으려면 새 게임의 세계관, 등장인물 칸에 이름을 정해 두고, 한 이름으로만 부르도록 적어 두세요 (위 "내 설정으로 시작" 참고).

To prevent it, settle the names in Setting and characters when you start a new game and ask for one name per person (see "Start with your own setup" above).

防ぐには、新しいゲームを始めるときに世界観と登場人物で名前を決めておき、一人につき名前はひとつにするよう頼んでください（上の「自分の設定で始める」を参照）。

2. 판정이 이상하게 서술돼요

2. A check is narrated strangely

2. 判定の語られ方がおかしい

가끔 주사위 결과와 이야기가 맞지 않아서 어색할 때가 있어요. 그럴 땐 /판정으로 이유를 물어보세요. 규칙에 어긋났다면 AI가 바로잡을 수 있어요. 계속 신경 쓰이면 주사위를 끄고 시작하는 방법도 있어요.

Sometimes the dice result and the story don't line up. Ask why with /why; if it broke the rules, the AI can fix it. If it keeps bothering you, start a life with the dice off.

ダイスの結果と物語がかみ合わないことがあります。/判定 で理由を聞いてください。ルールに反していれば、AIが直せます。どうしても気になるなら、ダイスをオフにして人生を始めてください。

3. 저장 공간이 가득 찼어요

3. Storage is full

3. 保存容量がいっぱい

  • 저장 탭에서 오래된 저장이나 분기를 이야기 내보내기로 파일에 담아 둔 다음 삭제하면 공간이 생겨요.
  • In the Saves tab, export old saves or branches with Export story, then delete them to free up space.
  • セーブタブで、古いセーブや分岐を物語の書き出しで書き出してから削除し、空きを作ってください。

그 밖의 제약

Other limits

そのほかの制限

  • claude.ai 아티팩트에서만 돌아가요. 일반 웹사이트로 열면 AI를 부를 수 없어요.
  • 저장은 그 아티팩트에 묶여 있어요. 업데이트할 때는 항상 같은 링크에 덮어쓰기로 하세요.
  • 이미지는 아티팩트마다 따로 저장돼요. 새 링크로 옮기면 다시 올리거나 팩 내보내기 파일을 쓰세요.
  • 이미지 업로드는 앱 소유자만 할 수 있어요. 게시된 링크에서 열어 주세요.
  • 사용량 한도는 Anthropic이 정해요. 한도에 자주 걸리면 최근 기억 분량을 줄여 보세요.
  • Runs only as a claude.ai artifact. Opened as a normal website, it can't call the AI.
  • Saves are tied to that artifact. Always update by overwriting the same link.
  • Images are stored per artifact. When you move to a new link, upload them again or use an Export pack file.
  • Only the app's owner can upload images. Open it from the published link.
  • Anthropic sets the usage limits. If you hit them often, lower the Recent memory size.
  • claude.ai のアーティファクトでのみ動きます。普通のWebサイトとして開くとAIを呼び出せません。
  • セーブはそのアーティファクトに紐づいています。アップデートは必ず同じリンクに上書きしてください。
  • 画像はアーティファクトごとに保存されます。新しいリンクに移るときは、アップロードし直すかパックを書き出すのファイルを使ってください。
  • 画像をアップロードできるのはアプリのオーナーだけです。公開されたリンクから開いてください。
  • 利用上限はAnthropicが決めます。よく上限に達するなら、最近の記憶の量を減らしてください。
